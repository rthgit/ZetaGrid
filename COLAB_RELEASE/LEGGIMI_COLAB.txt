1. **Upload su Colab**
   - Apri Google Colab (https://colab.research.google.com).
   - Crea un "Nuovo Notebook".

2. **Caricamento File**

     - `morph_checkpoint_latest.bin` (**OPZIONALE**: Se lo metti, riprende dallo step salvato. Se no, parte da 0).

3. **Esecuzione**
   - In una cella del notebook, esegui questi comandi:

```bash

```

4. **Avvio Training**
   - Una volta compilato (vedrai "Compilazione Riuscita!"), avvia il motore:

```bash

```
